# Insurance Claim Prediction

Machine Learning based Vehicle Insurance Claim Prediction System.

## Algorithm
Logistic Regression

## Selected Features
- subscription_length
- customer_age
- vehicle_age
- region_code
- region_density
- model
- engine_type
- segment

## Project Structure
- backend: Flask API and trained model
- frontend: HTML, CSS and JavaScript dashboard
- data: Dataset
- results: Model evaluation results

## Backend Run
pip install -r requirements.txt
gunicorn app:app
